# Pop-It-Santiago-Osorio
* Vista Previa
  * https://rrolface.github.io/Pop-It-Santiago-Osorio-/ 
* Descripcion y cositas agregadas :)
  
  * Esta pagina contiene informacion sobre los Pop-Its como ¿Que es?, ¿Cuales estan disponibles?, ¿Como usarlo? y el contacto.
    
  * En cuanto a lo destacable de la pagina le agregue un hero animado en cuanto a la imagen principal, animacion flotante de forma continua y el   fondo en el que esta la imagen tiene un blob que cambia de forma con el morphBlob.
    
  * Le agregue una interaccion al boton comprar de los Pop-Its el cual arroja un "Toast" de agregado al carrito con una barra de cuenta             regresiva.
    
  * Los botones tienen un efecto Ripple, una onda de expansion que sale del punto exacto donde haces clic.
    
  * Boton flotante de volver arriba para subir hasta el principio de la pagina.
    
  * Menu Hamburguesa para una experiencia totalmente responsive. PC y Celular.


* Tecnologias Usadas
  
  * HTML - Toda la estructura
    
  * CSS - Diseño, estilos y animaciones
    
  *JavaScript - Interactividad, scroll reveal, toast, menu hamburguesa, barra de progreso y efecto ripple
